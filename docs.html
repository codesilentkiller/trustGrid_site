TrustGrid Documentation

TrustGrid is a real-time fraud detection API that helps fintech companies, startups, and enterprises prevent fraudulent transactions. This documentation will guide you through integration, API usage, and understanding risk scoring.

⚡ Key Features
  • • Sub-25ms response time
  • • 5-factor weighted scoring model
  • • Behavioral profiling per user
  • • Multi-tenant architecture
  • • SOC2 compliant and GDPR ready

Quick Start

Get started with TrustGrid in 3 simple steps:

# 1. Install the SDK
npm install @trustgrid/node

# 2. Initialize with your API key
const trustgrid = new TrustGrid({
  apiKey: 'tg_v1_your_api_key_here'
});

# 3. Check a transaction
const result = await trustgrid.check({
  transaction_id: 'tx_001',
  user_id: 'user_123',
  amount: 5000,
  currency: 'USD'
});

console.log(result);
// { risk_score: 55, decision: 'flag', action: 'SOFT_DECLINE' }

Authentication

All API requests require an API key in the Authorization header:

Authorization: Bearer tg_v1_your_api_key_here

Generate your API key from the dashboard or via the API:

curl -X POST https://api.trustgrid.com/v1/keys \
  -H "Authorization: Bearer YOUR_ADMIN_KEY" \
  -d '{"name": "Production Key", "rate_limit": 500}'

Fintech Integration

For fintech companies processing payments, cards, or transfers:

// Banking/Fintech example
const result = await trustgrid.check({
  transaction_id: wire_transfer.id,
  user_id: account.owner_id,
  amount: wire_transfer.amount,
  payment_method: 'wire_transfer',
  device_id: session.device_fingerprint,
  ip_address: request.ip
});

if (result.decision === 'block') {
  await blockWireTransfer(wire_transfer.id);
  await alertFraudTeam({
    transaction: wire_transfer,
    risk_score: result.risk_score,
    factors: result.active_factors
  });
}

Startup Integration

For startups and early-stage companies:

// Startup/Payment processing example
const result = await trustgrid.check({
  transaction_id: payment.id,
  user_id: customer.id,
  amount: payment.amount,
  payment_method: 'credit_card',
  device_id: req.headers['user-agent']
});

if (result.decision === 'flag') {
  await sendTwoFactorCode(customer.phone);
  await logForReview(payment);
} else if (result.decision === 'approve') {
  await processPayment(payment);
}

Scoring Engine

TrustGrid uses a weighted multi-factor scoring model:

25% Amount Deviation - Statistical anomaly detection
20% Velocity Detection - Transaction frequency analysis
25% Location Intelligence - Geographic pattern analysis
10% Time Anomaly - Temporal pattern detection
20% Behavioral Profiling - User history comparison

Decision Logic

Risk ScoreDecisionActionSeverity
0-40APPROVEPROCESSNONE
41-69FLAGREQUIRE_2FAMEDIUM
70-100BLOCKREJECTHIGH

Why Transactions Are Flagged

💰 Amount Deviation

Transaction amount significantly exceeds user's historical average. Example: A user who typically sends $200 suddenly sends $10,000.

⚡ Velocity Spike

Multiple transactions in a short time window. Example: 5+ transactions in 5 minutes indicates card testing or automated fraud.

📍 Location Mismatch

Impossible travel or high-risk geography. Example: Transaction from New York and Tokyo within 30 minutes.

⏰ Time Anomaly

Transaction at unusual hours (1-5 AM). Example: Business user making a large transaction at 3 AM.

📱 New Device

Transaction from unrecognized device. Example: User's first transaction from a new phone or computer.
